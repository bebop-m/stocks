## 二、扣非 -25% 是会计切割的假摔

人民币上半年持续升值，美的外币资产产生汇兑损失（计入**经常性**的财务费用：从 +59.9 亿收入变为 -32.7 亿费用，摆动约 -92.6 亿）；而对冲这些敞口的衍生品收益（投资收益 30.4 亿 + 衍生品公允价值变动约 25 亿）按规则计入**非经常性**。损失留在扣非里、对冲收益被扣掉，扣非于是断崖。公司在报告里主动做了备注说明。

经济实质上汇率敞口大体对冲掉了。但反过来 +1.7% 的归母里也含约 28 亿权益工具投资浮盈（非经营项）和 11 亿商誉减值损失。拆干净后：**主业利润大致持平微增（营业利润 316.8 亿 vs 312.5 亿，+1.4%）**。另有其他综合收益里 -33.6 亿外币报表折算差额直接冲净资产，不过利润表。

| 机器人与自动化 | 166.2 亿 | +10.3% | 20.90% | -1.86pct |
| 工业技术 | 131.4 亿 | -12.7% | 14.75% | -2.13pct |

- 行业背景（美的引用 AVC）：H1 国内家电零售额 4,250 亿，**-9.9%**；出口 +2.4%。国内 +2.1% 是出货跑赢零售，和格力内销 +1.9% 同样存在渠道剪刀差问题，但美的自称日均自有库存同比 -16%、以零售实销驱动补货，渠道水位主张与格力「终端库存高企」表述相反，可信度待三季报验证。
- 海外占比 43.5%，OBM 收入已超过智能家居海外收入的 **50%**（东芝/Midea/Comfee），海外毛利率 26.28% 高于国内。
- 楼宇科技（中央空调+电梯+楼控）+10.8%，是与格力商用空调最接近的对照组；机器人 +10.3% 但毛利率 -1.86pct（KUKA 价格竞争）。工业技术 -12.7% 是唯一负增长分部（压缩机/电机等部件，受整机行业拖累）。

## 四、利润质量与资产负债表

- 销售费用 -6.5%（费率 8.3%→8.3%↓0.9pct）、研发 -3.4%：温和降费，不像格力砍 17%/19% 那种力度。
- **商誉减值 11.0 亿**（未披露具体资产组）。期末商誉仍有 315.8 亿，其中 KUKA 221 亿——这是美的资产负债表上最大的悬顶物，机器人毛利率还在往下走。
- 实际税率 15.0%→16.5%（格力 12.6%→16.8%，两家同向）。
- 应收账款 619.5 亿，较年初 +53%（有季节性，中报未给同比口径，幅度值得三季报跟踪）；存货较年初 -14%。
- 合同负债 454.6 亿，较年初仅 -3.3%；**销售返利池 569.7 亿，较年初 +40 亿**——计提大于使用，利润是往「藏」的方向走的。
- 现金流：销售收现 2,292.6 亿 +1.8%，OCF 375.5 亿，覆盖归母 1.42 倍。
- 股东回报：上半年已付 2025 年度分红约 284 亿（每股约 3.72 元），另**首次中期分红每 10 股 5 元（37.2 亿）**；H1 回购约 70 亿（库存股 81.5→151.2 亿，回购专户 1.80 亿股 ≈ 总股本 2.4%）。同期发债/可转债融资约百亿补流动性。归母净资产因此 -4.6%。

## 五、与格力对比（接 8-26 拆解）

| 维度 | 美的 | 格力 |
|---|---|---|
| H1 营收 / 归母 | 2,600 亿 +3.6% / 264.5 亿 +1.7% | 894 亿 -8.2% / 132.8 亿 -7.9% |
| **Q2 营收 / 归母** | **+4.6% / +1.3%** | **-16.8% / -15.4%** |
| 海外收入占比与增速 | 43.5%，+5.5%（OBM>50%） | 14.3%，-22.0% |
| ToB/第二曲线 | 25.6% 占比，楼宇+10.8%、机器人+10.3% | ~10% 占比，工业制品 -9.8% |
| 内销/国内 | +2.1%，毛利率 -0.27pct | +1.9%，毛利率 -2.62pct |
| 净利率 | 10.2% | 14.9% |
| 费用动作 | 销售 -6.5%、研发 -3.4% | 销售 -17.3%、研发 -19.0% |
| 合同负债（较年初） | 454.6 亿，-3.3% | 84.7 亿，-44%（同比 -31.7%） |
| 返利池 | 570 亿（+40 亿），占营收比小 | 485 亿（持平），相对体量约为美的 3 倍 |
| OCF / 销售收现 | 375.5 亿 +0.7% / +1.8% | 188.1 亿 -33.6% / -17.2% |
| 中期分红 | 首次，37.2 亿 | 暂不派发 |
| 股息率（2025 年度口径） | ≈4.3%（+回购≈2.4%股本） | ≈7.7%（+50-100 亿回购方案） |
| PE-TTM（08-28 收盘） | ≈14.9x（市值 ≈6,578 亿） | ≈7.8x（市值 ≈2,185 亿） |

**对上次 β/α 结论的更新**：美的交卷后，「Q2 下滑主要是行业 β」这个说法要收窄——β 是真的（国内零售 -9.9%、国补退坡），但美的证明了**结构可以免疫 β**：43.5% 海外 + 26% ToB 把国内 C 端周期稀释掉了。格力 Q2 -16.8% 里，行业逆风是背景，**86% 收入押在国内、80%+押在空调单品类的结构才是放大器**。同时美的国内 +2.1% vs 格力内销 +1.9% 几乎一样——纯内销盘上两家打平，格力输的不是国内竞争，是没有第二战场。

**格力相对占优的点**（上次结论仍成立）：净利率高 4.7pct、返利池相对厚 3 倍（利润平滑弹药）、无商誉汇率敞口、股息率高一倍、估值一半。美的相对占优：增长结构、现金流趋势、渠道蓄水池稳定、回报形式多元（分红+中期息+回购注销）。

**定价含义**：7.8x 的格力 vs 14.9x 的美的，市场买的不是过去半年的利润，是「单一品类内销年金（可能衰退）」vs「全球多元增长平台」两种叙事。这份中报让两个叙事各自都拿到了证据。

## 六、下半年跟踪点

1. 美的应收账款同比口径（三季报）；KUKA 所在机器人板块毛利率是否继续下探、商誉是否再减值。
2. 格力三季报合同负债是否企稳（上次定的第一跟踪点，本期尚未到验证时点）。
3. 两家 Q3 国内收入：2025Q4 起国补基数变低，若格力出货仍负增长，则 α 问题坐实。
4. 格力最终是否补中期分红；美的中期分红 14% 派息率是否常态化加码。
