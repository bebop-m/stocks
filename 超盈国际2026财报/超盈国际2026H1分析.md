# 超盈国际（2111.HK）2026 中期业绩拆解

数据来源：HKEX 公告《截至二零二六年六月三十日止六個月的中期業績公告》（2026-08-24 21:02 发布）与《截至二零二五年十二月三十一日止年度的全年業績公告》（2026-03-23）。H2'25 的数字均为「全年 − H1'25」推算。金额单位：千港元 / 百万港元。

收入是上半年历史新高，毛利率也在改善，但利润倒退。断层出在毛利以下。

## 二、税前利润桥式分解（−18.4 百万，已与报表逐项对平）

| 项目 | 影响 |
|---|---|
| 毛利增长 | **+92.0** |
| 三项费用（销售+行政+研发）增加 | **−56.6** |
| 其他收入减少（主因去年 21.0 的客户绩效花红今年归零） | −19.5 |
| 汇兑净额恶化（−37.3 vs −1.1） | **−36.2** |
| 贸易应收信贷亏损拨备 | −6.4 |
| 融资成本下降 | +8.4 |
| 分占合营 | −0.1 |
| **税前利润变动** | **−18.4**（291.4 vs 309.8） |

三个杀手：汇兑 −36.2、费用 −56.6、去年一次性花红 −21.0。融资成本改善（借款利率下行）和有效税率下降（12.6%→10.6%，越南 5% 优惠税率的利润占比上升）各接回来一点。

口径调整后的「经营性」利润：

- 剔汇兑：税前 328.7 vs 310.4，**+5.9%**
- 再剔一次性花红与滞销存货拨备：353.4 vs 286.9，**+23.2%**

第二个口径不能全信——滞销存货拨备 24.7 百万（去年同期是回拨 2.5 百万）是真实的存货质量问题，不是会计噪音。

## 三、真正的信号：主业在失血，靠织带补上

分部数据（H2'25 为推算）：

| | H1'25 | H2'25 | H1'26 |
|---|---|---|---|
| **面料及蕾丝** 收入 | 1,829.2 | 2,146.0 | 2,049.5 |
| 毛利率 | 27.6% | 27.5% | **26.6%** |
| 分部溢利率 | 16.9% | 15.9% | **13.1%** |
| **弹性织带** 收入 | 500.6 | 545.0 | 576.0 |
| 毛利率 | 23.0% | 23.1% | **29.2%** |
| 分部溢利率 | 11.1% | 11.2% | **17.2%** |

- 面料主业（占收入 78%）的分部溢利 267.8，**同比 −13.5%**，溢利率连续两个半年下滑，且 H1'26 加速。
- 织带分部溢利 99.2，**同比 +78.3%**，毛利率一口气从 23% 跳到 29.2%。
- 两者相加 367.1 vs 365.2，几乎持平——**集团层面的分部溢利完全是靠织带把面料的窟窿填平的**。

织带毛利率能否持续存疑。管理层自己给的解释是「生产规模经济效益增强，加上相较于二零二五年同期（当时我们在消化存货），已确认的主要原材料成本出现有利下降」——即去年 H1 在消化高价库存，今年是低基数。而 H2'25 织带毛利率仍是 23.1%，说明 29.2% 相对过去两年都是异常值。如果回落到 24–25%，H1 毛利要少 25–30 百万。

## 四、产品线：运动服装扛旗，内衣持续塌方

| 产品 | H1'25 | H2'25 | H1'26 | H1 同比 |
|---|---|---|---|---|
| 面料—运动服装及服装 | 1,230.6 | 1,569.2 | 1,511.9 | **+22.9%** |
| 面料—内衣 | 576.5 | 548.6 | 514.2 | **−10.8%** |
| 弹性织带 | 500.6 | 545.0 | 576.0 | +15.1% |
| 蕾丝 | 22.1 | 28.2 | 23.4 | +5.8% |

- 运动服装占收入比重从 52.8% 升至 57.6%，是唯一的增长引擎，管理层称核心客户普遍增长且拿到新客户增量订单。
- 内衣占比从 24.8% 掉到 19.6%，**连续两个半年环比下滑**（576.5 → 548.6 → 514.2）。这不是单期波动，是趋势。24.7 百万的滞销存货拨备大概率主要来自这里。
- 蕾丝已经不重要（占收入 0.9%），2025 全年同比 −17.8%。

## 五、汇兑：容易被误读的一项

37.4 百万汇兑亏损来自人民币上半年对美元升值约 3%。公司一半产能在中国大陆（人民币计价成本），销售以美元/港元计价——这是结构性的货币错配，**不是一次性事件**，人民币继续升值它就继续来。管理层在展望里也明说「预期人民币汇率将持续波动……进而对我们的业务及盈利能力造成影响」。

但另一面：其他全面收益里「换算海外业务产生的汇兑差额 **+133.8** 百万」（去年同期 +16.8）。全面收益总额 393.6 vs 287.2，**+37.0%**。也就是说人民币升值对集团净资产是净有利的，只是损益表被记了一笔（含集团内往来账户重估的账面部分）损失。只看归母溢利 −3.2% 会低估这半年的实际增益。

## 七、地域

- **越南**：收入同比 +25.2%，是集团获利能力最强的生产中心（享 5% 优惠所得税率），也是有效税率从 12.6% 降到 10.6% 的主因。乂安新厂一期 2027 Q1 试产，届时集团总产能 +10%–15%。
- **斯里兰卡**：全国纺织服装出口 −6.1% 的背景下，公司当地基地收入和净利润「均实现稳定增长」（未给绝对数）。
- **中国大陆**：约占一半产能，是汇兑亏损的来源。

当前年设计产能：弹性面料 284.3 百万米、弹性织带 2,045.9 百万米、蕾丝 46.0 百万米。员工 12,802 人（年末 11,826，半年增 976 人）。

## 九、H2 的三个变量

1. **涨价谈判**——管理层原话：「已与核心品牌伙伴展开建设性且透明的讨论，以探讨调高价格的可能性……若品牌客户提出任何异议，将使我们在二零二六年下半年的利润率面临风险。」这是最直接的胜负手。上半年靠 2–3 个月存货缓冲扛住了 2 月底以来的原材料涨价，缓冲下半年用完。
2. **油价**——Q2 以来在 70–120 美元/桶区间剧烈波动（4 月因霍尔木兹海峡冲突冲到近 120）。合成纤维直接挂钩。上半年原材料占收入比其实还降了（32.8%→32.0%），全靠库存缓冲。
3. **人民币汇率**——继续升值就继续吃损益，且下半年没有去年的低基数保护。

## 十、结论

**这是一份「营收拐点确立、利润质量待验证」的中报。**

好的地方：收入创上半年新高且加速（+12.7%，2024/2025 连续两年是零增长到负增长）；运动服装赛道 +22.9% 说明拿到了份额；越南税盾在加深；应收干净；资产负债表极其干净（净负债率 6.3%）；股息率两位数，派息率纪律稳定在 50%。

坏的地方：**主业面料的分部溢利率从 16.9% 掉到 13.1%，这是两年来的第三个连续下滑半年**，靠一块可能不可持续的织带高毛利填平；内衣线连续两个半年萎缩；存货天数和滞销拨备同时恶化；本期股息已经不被自由现金流覆盖，而 H2 还有 5–10 亿港元的乂安建设款要付。

估值确实便宜到扎眼（PE 4.8x / PB 0.65x / EV/EBITDA 2.5x / 股息率 10.6%），但便宜有便宜的理由：B2B 面料代工没有定价权（涨价要「和客户商量」），26 亿市值的港股小盘流动性极差（业绩前一日成交仅 27 万股），三重外部变量（油、汇、关税）都不在自己手里。

**要跟踪的两件事**：一是 H2 涨价谈成没有——直接看 2027 年 3 月年报的 H2 毛利率；二是面料分部溢利率是否止跌——如果 H2 继续往下，那织带的一次性红利用完之后，2027 年的利润会很难看。

# 补充：负债率与 EPS 可持续性（2026-08-25 追加）

## 十一、负债率：三个口径都很安全

| | 2026-06-30 | 2025-12-31 |
|---|---|---|
| 总资产 | 7,370.3 | 6,662.9 |
| 总负债 | 3,234.0 | 2,774.6 |
| **资产负债率** | **43.9%** | 41.6% |
| 有息负债（借款+租赁） | 1,892.0 | 1,654.6 |
| 有息负债/总资产 | 25.7% | 24.8% |
| 现金+抵押存款 | 1,398.6 | 1,127.5 |
| **净债务（公司口径，不含租赁）** | **259.7** | 247.9 |
| **净负债率（净债务/权益）** | **6.3%** | 6.4% |
| 净债务（含租赁） | 493.4 | 527.1 |
| 净负债率（含租赁） | 11.9% | **13.6%** |
| 流动比率 / 速动比率 | 1.97 / 1.19 | 1.94 / 1.19 |

- **净债务/TTM EBITDA = 0.22x**（含租赁 0.43x）。基本等于没有杠杆。
- **EBIT/利息 9.7x**（H1'25 8.4x），**EBITDA/利息 17.1x**，覆盖倍数还在改善（融资成本 −20.2%）。
- 现金 1,302.9 对一年内到期借款 579.9，**覆盖 2.25x**。银行借款期限结构分散：1 年内 564.6 / 1–2 年 513.1 / 2–5 年 449.5。
- 资产负债率上升 2.2pp，来源是借款 +282.8（为乂安备粮）和存货 +259.8，不是经营性恶化。
- 有意思的一点：**含租赁口径的净负债率反而从 13.6% 降到 11.9%**——期内净偿还了约 96 百万租赁负债。公司披露的 6.3% 口径把租赁排除在外，偏宽松，但即使按含租赁的严格口径也只有 11.9%。

**H2 会怎么变**：乂安一期 capex 5–10 亿港元，管理层明说大部分在 H2 结清。H2 现金流出还包括 7 月已付的 2025 末期股息 145.6 和 10 月 9 日要付的中期股息 125.8，合计 271.4。若 H2 经营现金流与 H1 相当（约 307）、H2 capex 400，则需新增净借款约 365，净债务从 259.7 升至 600–700，**净负债率升到 14%–17%**——仍属极低。管理层的说法是「尽管杠杆比率出现暂时性上升，本集团的净资产负债比率预测会维持在保守的低水平」。

**结论：负债率不是这家公司的风险项。** 唯一值得留意的是股息的现金覆盖——H1 自由现金流 77 百万 vs 中期股息 125.8 百万，扩产期的分红有一部分是借来的。但以 0.22x 的净债务/EBITDA，这个做法可持续。

## 十二、EPS 能否稳住：门槛、情景与敏感度

### 门槛

2026 全年 EPS 要持平 2025 的 53.02 港仙 → H2 归母需 ≥ **299.2 百万**（H2'25 实际 290.9，即 **+2.8%**）→ 对应 H2 归母净利率 ≥ **9.97%**（H1'26 实际 9.61%）。

**不是很高的门槛，但要求 H2 的利润率比 H1 略有回升。**

### H2'25 基准（推算，用于对照）

收入 2,691.0 / 毛利率 26.63% / 其他收入 40.9（**含 21.0 绩效花红**）/ 汇兑 −8.1 / 税前 322.4 / **实际税率 7.9%** / 归母 290.9（归母率 10.81%）

> 关键发现：2025 全年绩效花红 **42.0** 百万，H1 与 H2 各 21.0。该计划已终止，所以 **H2'26 同样背着 21.0 的逆风，不只是 H1**。
> 另一个被忽略的顺风：**H2 的实际税率历来远低于 H1**（H2'25 仅 7.9%，H1'25 12.6%，全年 10.2%），越南（5% 优惠税率）利润占比上升还在加深这一点。

### 敏感度（中性情景，H2 收入 30 亿）

- **毛利率 ±1pp → EPS ±2.53 港仙**（±4.8%）← 压倒性的主导变量
- 收入 ±5% → EPS ±3.35 港仙
- 汇兑 ±10 百万 → EPS ±0.84 港仙

### 判断

**EPS 大概率能稳住，中枢约 52–53 港仙，但这是个「刚好持平」的结论，不是有余量的结论。**

支持稳住的：
1. H2 税率历来 8% 左右，比 H1 的 10.6% 还低约 2pp，单这一项就贡献约 1.5 仙 EPS；
2. H2 收入季节性高于 H1 约 15%，规模效应摊薄固定成本；
3. 管理层称「对年内剩余月份维持稳定的销售增长预测」，订单趋势明确；
4. 融资成本仍在下行通道（H1 已 −20.2%）；
5. 人民币若企稳，H1 的 −37.4 汇兑就是最大的一次性改善来源。

拖后腿的：
1. **原材料**——H1 靠 2–3 个月存货缓冲挡住了 2 月底以来的涨价，H2 缓冲用完，高价料要进成本；
2. **织带毛利率 29.2% 大概率回落**（H2'25 是 23.1%），按 H2 织带收入约 620 估，回到 25% 就少约 26 百万毛利 ≈ 2.2 仙 EPS；
3. **绩效花红 −21.0** 的逆风 H2 同样存在；
4. 乂安投产前费用在 H2 只会更多；
5. 内衣线继续萎缩的话，滞销存货拨备可能继续计提。

**一切压在毛利率上**：H2 毛利率 26.5% 是持平线，25.3% 就是 −11%，27.5% 就是 +12%。而毛利率的决定因素只有一个——**涨价谈成没有**。管理层的措辞是「探讨调高价格的可能性」和「若品牌客户提出任何异议，将使我们在下半年的利润率面临风险」，这是风险提示，不是既成事实。
