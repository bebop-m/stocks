## 怎么打开

双击 **`启动阅读.cmd`**，浏览器会自动打开 http://127.0.0.1:8899/。按 `Ctrl+C` 或关掉黑窗口即停止。

也可以手动运行：

```
python serve.py 8899
```

> **必须通过这个脚本打开，不要直接双击 `site/` 里的 html 文件。**
> 站点是 Nuxt 单页应用，客户端路由按 `/benfen` 这样的无后缀地址匹配；
> 直接用 `file://` 打开虽然能看到正文，但侧栏跳转、全文搜索都会失效。
